Local motion engine

Build reusable motion packages. Render them on your machine.

ShellX Motion is the rendering engine shared by ShellX Cut and Design Studio. It turns data-only packages into preview frames, final video, image sequences, and durable receipts. It can also run by itself through the Engine Room or its command line.

Install and verify the source release

Motion v0.2.65 ships as source. Use Node.js 24, pnpm 10.6 or newer, and install FFmpeg plus FFprobe for final video. Validation and native still previews work without the codec tools.

pnpm install --frozen-lockfile pnpm build pnpm --filter @shellx-motion/cli run cli -- doctor pnpm --filter @shellx-motion/cli run cli -- validate fixtures/packages/lower-third

Use Engine Room without typing paths

Engine Room is Motion's local workbench. Start Motion and it opens already unlocked with local access bounded by host-owned roots. Authoring package/revision roots come from the launch command; package, render-output, quality-manifest, and receipt Browse results grant only the exact human-selected locations for the current session.

Local render pipeline

Choose the simplest renderer that preserves the design

Native framesFast deterministic stills for supported shapes, text, gradients, images, and effects. No browser required.
Browser framesChromium draws richer HTML and CSS scenes, fonts, video, and browser-backed effects.
FFmpeg outputEncodes browser or native frames into MP4, WebM, GIF, stills, or image sequences and records the actual encoder used.

H.264 MP4 and VP9 WebM are the broad compatibility defaults. HEVC and AV1 depend on the local FFmpeg build and available hardware. Motion probes hardware encoders before using them and records any software fallback in the render receipt.

pnpm --filter @shellx-motion/cli run cli -- render fixtures/packages/lower-third --out .scratch/first-render.mp4

Verify the result

Every delivered render returns a receipt

A render receipt records the package identity, input and output hashes, renderer, encoder, dimensions, duration, quality checks, warnings, and actor evidence. Engine Room History turns persisted records into a readable timeline and can open the output's containing folder. CLI renders write an output-sidecar copy; Debug/MCP renders persist under a governed receipt root when the caller or server supplies one.

  1. Match the package.Confirm the package id and inputs are the ones you intended.
  2. Read the result.A warning is not a pass; inspect the named gate and fallback.
  3. Match the output.Confirm the file path and SHA-256 hash before delivery.

Validation returns its result directly and creates no receipt file only without an explicit governed receipt destination. Package-producing batch operations keep their own receipts inside the package they create.

Security model

Local by default, bounded by capability

Loopback only

The workbench and agent server listen on this computer and use one private per-user key for non-public routes.

Declarative layers are data; web layers run code

Shapes, text, keyframes, environments, particles and fixed 3D scenes declare what to draw and cannot execute anything or raise resource limits. A web, html or canvas layer is the deliberate exception: it loads package-local HTML in Chromium with JavaScript enabled. Treat a package from an untrusted source the way you would treat any downloaded script.

No project telemetry

Update checks request only the configured release channel. Project files, prompts, and render content are not sent.

Chromium and FFmpeg still parse complex media. Treat untrusted packages as untrusted input, keep the tools patched, and use the lowest permission tier that can finish the job.

Shared release status

Motion checks for updates automatically

When a release channel is configured, Motion checks at startup and every 30 minutes. The About page and connected agents read the same cached status. Check now refreshes it immediately. A source checkout is updated through the same source workflow used to install it; Motion does not silently replace source files.

Troubleshooting

Start with the machine readiness report

Final video is unavailable

Run doctor. Install both FFmpeg and FFprobe, or configure their executable paths, then restart Motion.

Browser preview cannot start

Install the Chromium build required by Playwright. Native previews remain available for supported scenes.

Workbench is disconnected

Open Motion through pnpm start for an automatic local connection. Advanced Debug API clients can copy the local key from Connections after Motion starts.

A Browse button does nothing

Native pickers require a desktop session. On Linux, install Zenity or KDialog; on Windows and macOS the operating-system picker is used.

A render completed with warnings

Open History, inspect the quality and encoder details, and resolve the warning before treating the artifact as approved.
