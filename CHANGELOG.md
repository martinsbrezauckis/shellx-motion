# ShellX Motion changelog

This changelog describes user-facing capability. Internal checkpoints and detailed remediation
history remain in the private roadmap and release evidence.

## 0.2.65 — release candidate

- Added a self-describing Motion-to-Cut connector contract with runtime discovery, generic job
  submission, lifecycle events, cancellation, artifact handoff and bounded opaque errors.
- Added typed Action, CLI, Debug HTTP, WebSocket and MCP surfaces for package authoring, previews,
  renders, batch workflows, job control, support bundles and receipt inspection.
- Added copy-on-write package creation, patching, asset import, template data binding and portable
  package/render lineage evidence under host-owned input and output roots.
- Added deterministic recipe and checkpoint authoring for geometry, text, keyframes, paths,
  procedural traces, multi-object choreography and bounded Scene3D scenes.
- Added browser, native, FFmpeg and WebGPU delivery lanes with still, image-sequence, H.264, WebM,
  GIF and professional intermediate presets where the capability catalog marks them supported.
- Added a machine-readable rendering-sample catalog linking supported families to checked examples,
  canonical invocations, artifact shapes, receipt shapes and explicit limitations.
- Added durable receipts, final package-lineage binding, authenticated render-reuse evidence,
  deterministic SBOM generation and fail-closed local process/root boundaries.
- Hardened caller path-role admission across package discovery, templates, archives, review/support
  bundles and tracking; strict GPU HTML URL closure; raw-prompt retention admission; and aborted
  quality-gate receipt evidence.
- Bugfixes.

## 0.1.0 — public baseline

- Introduced the ShellX-owned Motion package, MotionIR, templates, local browser/native preview,
  FFmpeg export, batch rows, receipts and initial Design Studio/Canvas/Cut connector foundations.
- Bugfixes.
