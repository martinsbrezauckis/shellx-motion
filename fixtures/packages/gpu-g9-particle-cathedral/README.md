# Particle Cathedral — G9 GPU Film

Creative intent: a dark, editorial-scale field of gold and cyan light gathers around an unstable warm core before the title resolves. The film is deliberately composed at 1920×1080 for a full-frame product reel, rather than being a diagnostic clip.

The `hundred-thousand-lights` layer is exactly 100,000 seeded, analytic-field particles. It is valid only through the fixed Motion-owned GPU compute route: circular heads, three bounded radial/vortex sources, normal composition, and no package-supplied shader, trail, mask, matte, or temporal history. It is above the portable CPU admission tier by design.

Inter files are copied byte-for-byte from the checked-in ShellX Motion product pack and remain under SIL OFL 1.1 (`assets/fonts/LICENSE-Inter.txt`).

Hardware proof is pending. Render later only with `render --lane ffmpeg --frame-lane gpu` on an approved native GPU host, retaining representative frames, final media hash, FFprobe facts, quality result, GPU producer evidence, frame timing, peak memory, and visual review. This source fixture makes no final-render, performance, or cross-platform hardware claim.
