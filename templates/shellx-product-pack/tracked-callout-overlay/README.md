# ShellX Tracked Callout Overlay

A technical product explainer with synchronized callout dot, leader, panel and copy keyframes over a replaceable scene. The baked path demonstrates the final tracked behavior and is ready to be replaced by Motion point or planar tracking output.

Replacing `heroMedia` with a different target requires a new tracking pass; this
template does not pretend the sample coordinates transfer automatically.
Typography is pinned to package-local Inter Latin faces (SIL OFL 1.1; see
`assets/fonts/LICENSE-Inter.txt`) and the generated sample is
redistribution-safe. Its GPU lane remains strict: it requires live admitted
WebGPU hardware and never falls back to browser or CPU rendering.
