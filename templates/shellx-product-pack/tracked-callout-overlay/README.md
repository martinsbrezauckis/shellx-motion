# ShellX Tracked Callout Overlay

A technical product explainer with synchronized callout dot, leader, panel and copy keyframes over a replaceable scene. The baked path demonstrates the final tracked behavior and is ready to be replaced by Motion point or planar tracking output.

Replacing `heroMedia` with a different target requires a new tracking pass; this template does not pretend the sample coordinates transfer automatically. Typography uses the host sans-serif stack and the generated sample is redistribution-safe.
